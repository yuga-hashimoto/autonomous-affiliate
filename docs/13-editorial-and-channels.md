# 13. 記事テーマ・掲載先・収益導線（ジャンル非依存）

状態: 記事案はすべて未検証の候補。実際のジャンルは需要・競合・ASP承認後に選ぶ。

## 原則
AIやSaaSを固定テーマにしない。市場調査後、読者層が統一された**専門サイト**を一つ公開する。紹介商品の購入、使用・体験、営業、個別連絡をしない。公式の条件・費用・申し込み手順を比較して価値を出す。

## 調査対象と記事の型

| カテゴリ例 | 購買クエリを狙う記事例 | 独自の比較要素 |
|---|---|---|
| 格安SIM | 3GB/20GBの2年総額比較 | 月額・通話・初期費用・割引適用条件 |
| 光回線 | マンションと戸建ての実質費用比較 | 工事費・期間・解約料・エリア |
| 宅配買取 | ゲーム/本/カメラの宅配買取先比較 | 送料・返送料・買取対象・査定の流れ |
| 資格講座 | 資格名の通信講座料金比較 | 受講期間・教材・返金条件 |
| 転職 | 職種・地域別の転職サービス比較 | 対象職種・面談条件・求人の特色 |
| 引っ越し | 一括見積もりと個別見積もり比較 | 対応エリア・申込後の連絡方式 |
| 電力/ガス | 世帯人数と使用量別の料金比較 | 料金単位・燃料調整・キャンペーン |
| ウォーターサーバー | 月24L/48L総費用比較 | 水代・送料・電気代・解約金 |
| 車買取 | 複数社査定と一括査定の違い | 申込方式・業者連絡・対象条件 |
| B2B/SaaS | 公式料金とプラン機能の比較 | 従量制、アカウント数、機能制約 |

これらは市場需要・紹介案件存在・収益性が検証済みではない。競合に勝てるかはdocs/15-market-validation.mdの評価後に決める。

## 記事テンプレート
1. 読者の目的/予算/対象地域を定義し、PR/広告を明示
2. 公式のサービス条件・料金・例外・確認日・出典を並べて比較
3. 適用条件を揃えた独自の総額試算または選定マトリクス
4. 向かないケース、違約金、対象外、キャンセル条件
5. 契約済み広告主の公式発行リンクによるCTA（rel=sponsored）
6. 注意: 実際に使用していないのに使用レビューを装わない

## どこで公開し、どこで紹介するか
- P0: **自社の専門比較サイト（Astro/独自ドメイン）**に記事を自動公開。検索ユーザー向けの正本。
- P0: **Google検索**経由の自然流入。適切なsitemap/canonical/内部リンクを整備。
- P1: YouTubeで費用比較を図解し、自社記事へ誘導。著作権・公式API/媒体規約/広告表記を満たす場合のみ。
- P1: Xで比較の要点や条件変更を自動投稿し自社記事へ誘導。許可された公式API/媒体規約/PR表示必須。
- P2: 自発的登録者へのメール。配信同意と解除機能が必要。
- 禁止: スパムDM、許可のないSNS大量投稿、レビューの捏造。

## 90日計画
- Day 1–14: ASP・カテゴリ横断の探索、SERP競合、検索需要、広告主審査条件、報酬モデルを整理。
- Day 15–30: 条件を満たすジャンルの専門サイトと最初の2〜3記事、独自の表・計算機を生成。
- Day 31–60: 追加記事、Search Console、CTA計測を接続し、複数記事を比較。
- Day 61–90: 承認成果・流入が観測されたものへ制作配分を最適化。データ不足なら探索継続。

結論: **先に売れるジャンルを調べ、その後に記事を選ぶ。** 記事ありきではない。
